Глава 5. Уравнения с двумя переменными и их системы (Мерзляк, Профиль)

§ 33–35. Уравнения с двумя переменными и геометрические образы

Построение графиков уравнений на плоскости. График уравнения |x| + |y| = a (квадрат), уравнения вида (x - a)² + (y - b)² = 0 (точка) и xy = 0 (объединение координатных осей).

Пример: Графиком (x - 2)(y + 3) = 0 является совокупность двух пересекающихся прямых x = 2 и y = -3.
§ 36–37. Аналитические методы решения систем

Метод подстановки и алгебраического сложения для уравнений с дробными коэффициентами и скобками. Метод замены переменных для нелинейных уравнений, сводящихся к линейным.

Пример: Замена u = 1/(x+y), v = 1/(x-y) позволяет решить систему дробно-рациональных уравнений.
§ 38–39. Системы уравнений с параметрами

Исследование числа решений системы линейных уравнений с параметром k. Случаи единственного решения, параллельности и совпадения прямых на плоскости.

Условие: Система a₁x + b₁y = c₁ и a₂x + b₂y = c₂ имеет ∞ решений при a₁/a₂ = b₁/b₂ = c₁/c₂.
§ 40. Уравнения в целых числах (Диофантовы уравнения)

Решение уравнений вида ax + by = c в целых числах (x, y ∈ Z). Условие разрешимости: c должно делиться на НОД(a, b). Метод выделения целой части.

Пример: 3x + 5y = 11 ⇒ x = (11 - 5y)/3 = 3 - y + (2 - 2y)/3. Выражение (2 - 2y)/3 должно быть целым числом.
