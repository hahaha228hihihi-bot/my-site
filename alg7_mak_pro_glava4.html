Глава 4. Одночлены и многочлены (Макарычев, Профиль)

§ 23. Одночлены и степень одночлена

Степенью ненулевого одночлена стандартного вида называют сумму показателей степеней всех входящих в него переменных. Степень числа (ненулевого коэффициента) считается равной нулю.

Пример: Степень одночлена 7x3y2z равна 3 + 2 + 1 = 6.
§ 24. Действия над одночленами

Сложение и вычитание одночленов возможно только для подобных одночленов. При умножении и возведении в степень применяются правила действий со степенями с любыми основаниями.

Пример: (-2a2b)3 * (3ab) = (-8a6b3) * 3ab = -24a7b4.
§ 25. Многочлены от одной переменной и их степени

Степенью многочлена стандартного вида называется наибольшая из степеней входящих в него одночленов. Многочлен n-й степени от переменной x записывается как P(x) = anxn + ... + a1x + a0.

Пример: P(x) = 5x4 - 3x2 + 7 — многочлен 4-й степени со старшим коэффициентом 5 и свободным членом 7.
§ 26. Сложение и вычитание многочленов

Теорема о степени суммы: степень суммы двух многочленов не превосходит наибольшей из степеней слагаемых. Раскрытие вложенных скобок разного типа: круглых, квадратных и фигурных.

Пример: (2x3 + x) - (2x3 - 5) = x + 5 (степень понизилась с 3 до 1).
§ 27. Умножение многочленов

Степень произведения двух ненулевых многочленов в точности равна сумме степеней сомножителей: deg(P * Q) = deg(P) + deg(Q). Умножение трех и более многочленов производят последовательно.

Пример: (x + 1)(x + 2)(x + 3) = (x2 + 3x + 2)(x + 3) = x3 + 6x2 + 11x + 6.
§ 28. Метод неопределенных коэффициентов

Два многочлена тождественно равны тогда и только тогда, когда коэффициенты при одинаковых степенях переменной равны. Этот метод используется для нахождения неизвестных параметров.

Пример: Если ax2 + bx + c = 3x2 - 5, то a = 3, b = 0, c = -5.
§ 29. Деление многочленов с остатком («уголком»)

Для любых многочленов A(x) и B(x) ≠ 0 найдутся такие многочлены Q(x) (частное) и R(x) (остаток), что A(x) = B(x) * Q(x) + R(x), причем степень R(x) строго меньше степени B(x).

Определение: Если R(x) = 0, говорят, что многочлен A(x) делится на B(x) нацело.
§ 30. Теорема Безу и корни многочленов

Теорема Безу: остаток от деления многочлена P(x) на двучлен (x - c) равен значению многочлена в точке c, то есть R = P(c). Если P(c) = 0, то c — корень многочлена, и P(x) делится на (x - c) без остатка.

Пример: Для P(x) = x3 - 1 остаток от деления на (x - 1) равен P(1) = 13 - 1 = 0.
§ 31. Схема Горнера

Специальная удобная табличная схема для быстрого деления многочлена на двучлен (x - c) и одновременного вычисления значения многочлена P(c).

Правило: Старший коэффициент сносится без изменений, каждое следующее число вычисляется как c * (предыдущий результат) + текущий коэффициент.
