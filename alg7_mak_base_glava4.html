Глава IV. Многочлены (Макарычев, База)

§ 24. Многочлен и его стандартный вид

Многочленом называется сумма одночленов. Приведение многочлена к стандартному виду — это приведение всех входящих в него подобных слагаемых и запись каждого одночлена в стандартном виде.

Пример: 2x2 + 3x - x2 + 5 = x2 + 3x + 5.
§ 25. Сложение и вычитание многочленов

Если перед скобками стоит знак «+», скобки опускаются с сохранением знаков. Если знак «-», знаки всех слагаемых внутри скобок меняются на противоположные.

Пример: (3a - b) - (a - 2b) = 3a - b - a + 2b = 2a + b.
§ 26. Умножение одночлена на многочлен

Чтобы умножить одночлен на многочлен, нужно умножить этот одночлен на каждый член многочлена и полученные произведения сложить: a(b + c - d) = ab + ac - ad.

Пример: 2x(x2 - 4) = 2x3 - 8x.
§ 27. Вынесение общего множителя за скобки

Разложение многочлена на множители — представление его в виде произведения. Общий множитель всех членов выносится за скобки (наибольший общий делитель коэффициентов и переменные в наименьшей степени).

Пример: 6x3 - 9x = 3x(2x2 - 3).
§ 28. Умножение многочлена на многочлен

Чтобы умножить многочлен на многочлен, нужно каждый член одного многочлена умножить на каждый член другого многочлена и сложить результаты: (a + b)(c + d) = ac + ad + bc + bd.

Пример: (x + 2)(x + 3) = x2 + 3x + 2x + 6 = x2 + 5x + 6.
§ 29. Способ группировки

Слагаемые объединяют в группы, имеющие общий множитель, выносят общий множитель из каждой группы, после чего выносят полученный общий для всех групп двучлен.

Пример: ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b).
§ 30. Доказательство тождеств

Для доказательства тождества преобразуют левую часть к виду правой, либо правую к виду левой, либо находят их разность: если она равна 0, тождество верно.

Пример: (a - 1)(a + 1) = a2 - 1. Разность: a2 - 1 - (a2 - 1) = 0.
§ 31. Деление одночлена и многочлена на одночлен

Чтобы разделить многочлен на одночлен, нужно каждый член многочлена разделить на этот одночлен и сложить результаты: (a + b) : c = (a : c) + (b : c).

Пример: (12a3 - 8a2) : (4a) = 3a2 - 2a.
