Глава 6. Линейная функция и её свойства (Макарычев, Профиль)

§ 40. Область определения и область значений функции

D(f) — множество всех допустимых значений аргумента x. E(f) — множество всех значений, которые принимает зависимая переменная y. Для любой линейной функции y = kx + b (k ≠ 0) D(f) = R и E(f) = R.

Пример: Для константной функции y = 5: D(f) = R, а E(f) = {5}.
§ 41. Монотонность (возрастание и убывание функции)

Функция возрастает, если большему значению аргумента соответствует большее значение функции. Функция убывает, если большему x соответствует меньший y. Линейная функция y = kx + b возрастает при k > 0 и убывает при k < 0.

Пример: y = -3x + 1 убывает на всей числовой прямой, так как k = -3 < 0.
§ 42. Геометрический смысл углового коэффициента k

Коэффициент k равен тангенсу угла наклона прямой к положительному направлению оси Ox: k = tg(α) = (y₂ - y₁) / (x₂ - x₁). Если угол острый — k > 0, если тупой — k < 0.

Формула: Через точки A(1; 2) и B(3; 8) проходит прямая с k = (8 - 2) / (3 - 1) = 3.
§ 43. Условие перпендикулярности двух прямых

Две невертикальные прямые y = k₁x + b₁ и y = k₂x + b₂ взаимно перпендикулярны тогда и только тогда, когда произведение их угловых коэффициентов равно -1: k₁ * k₂ = -1 (или k₂ = -1 / k₁).

Пример: Прямые y = 2x + 1 и y = -0,5x - 4 взаимно перпендикулярны, так как 2 * (-0,5) = -1.
§ 44. Кусочно-заданные функции

Функции, которые задаются разными формулами на различных участках числовой оси. График строится отдельно для каждого промежутка с учетом выколотых или закрашенных граничных точек.

Пример: y = x при x ≥ 0; y = -x при x < 0 (это функция y = |x|).
§ 45. Графики функций, содержащих переменную под знаком модуля

Для построения графиков вида y = |kx + b| находят нуль подмодульного выражения (вершину «уголка») и раскрывают модуль по определению для областей справа и слева от него.

Пример: y = |x - 2|. При x ≥ 2: y = x - 2; при x < 2: y = -x + 2. График имеет форму уголка с вершиной в (2; 0).
§ 46. Преобразования графиков: f(x) + c и f(x + c)

Параллельный перенос: y = f(x) + c сдвигает график вдоль оси Oy вверх на c (при c > 0); y = f(x + c) сдвигает график вдоль оси Ox влево на c (при c > 0).

Пример: y = |x| + 3 — сдвиг базового уголка на 3 единицы вверх по оси Oy.
