Глава 2. Алгебраические выражения и уравнения (Макарычев, Профиль)

§ 8. Числовые равенства и их свойства

Если к обеим частям верного равенства прибавить одно и то же число, получится верное равенство. Если обе части верного равенства умножить или разделить на одно и то же ненулевое число, равенство останется верным.

Свойство: Если a = b и c = d, то a + c = b + d и ac = bd.
§ 9. Алгебраические выражения и область определения

Область определения (допустимые значения переменных) — это множество значений переменных, при которых выражение имеет числовой смысл. Деление на ноль строго исключается.

Пример: Для выражения 5 / (x - 3) допустимыми являются все действительные числа, кроме x = 3.
§ 10. Тождественные преобразования выражений

Углублённое доказательство тождеств, применение свойств сложения и умножения к громоздким выражениям со скобками и переменными знаками.

Пример: Доказать тождество: a(b - c) + b(c - a) + c(a - b) = ab - ac + bc - ba + ca - cb = 0.
§ 11. Равносильность уравнений. Теоремы о равносильности

Два уравнения называют равносильными, если множества их корней совпадают. Уравнения без корней также равносильны между собой. Перенос слагаемых и умножение на число, не равное 0, сохраняют равносильность.

Определение: Переход к неравносильному уравнению может привести к потере корней или появлению посторонних корней.
§ 12. Линейные уравнения и исследование корней

Исследование уравнения ax = b: 1) Если a ≠ 0, то один корень: x = b/a; 2) Если a = 0 и b = 0, то корнем является любое действительное число (x ∈ R); 3) Если a = 0, а b ≠ 0, то уравнение не имеет корней (∅).

Пример: 0 * x = 5 ⇒ нет корней. 0 * x = 0 ⇒ x — любое число.
§ 13. Уравнения с параметрами

Параметр — фиксированное, но неизвестное число. Решить уравнение с параметром a — значит для каждого значения a найти все значения x или доказать, что их нет.

Пример: ax = 4. При a = 0 корней нет; при a ≠ 0 корень x = 4/a.
§ 14. Уравнения с модулем (|x|)

Модуль числа — расстояние на координатной прямой от нуля до точки. По определению: |x| = x при x ≥ 0 и |x| = -x при x < 0. Уравнение |f(x)| = a при a > 0 распадается на два: f(x) = a или f(x) = -a.

Пример: |2x - 3| = 5 ⇒ 2x - 3 = 5 (x = 4) или 2x - 3 = -5 (x = -1).
§ 15. Сложные текстовые задачи на движение и работу

Задачи на движение протяжённых тел (поездов мимо столба/моста), движение навстречу с задержками и задачи на совместную работу, где вся выполненная работа принимается за 1.

Формула работы: A = p * t, где p — производительность, t — время. Совместная производительность: p = p₁ + p₂.
