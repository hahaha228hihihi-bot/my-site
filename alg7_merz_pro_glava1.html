Глава 1. Введение в алгебру. Линейные уравнения (Мерзляк, Профиль)

§ 1. Алгебраические выражения. Числовые множества

Числовые множества: натуральные (N), целые (Z), рациональные (Q) и действительные (R). Определение допустимых значений переменных (область определения выражения).

Пример: Для выражения (x + 2) / (x - 5) область определения: x ≠ 5.
§ 2. Уравнение с одной переменной. Равносильность

Понятие равносильных уравнений. Теоремы о переносе слагаемых и умножении на ненулевые выражения. Уравнения-следствия и появление посторонних корней.

Определение: Если множества корней двух уравнений совпадают, они называются равносильными.
§ 3. Линейное уравнение ax = b и исследование его корней

Полное аналитическое исследование: при a ≠ 0 — один корень x = b/a; при a = 0, b = 0 — корней бесконечно много (x ∈ R); при a = 0, b ≠ 0 — корней нет (∅).

Пример: (a - 2)x = a² - 4. При a = 2: 0*x = 0 (x — любое); при a ≠ 2: x = a + 2.
§ 4. Уравнения с параметрами

Методы решения линейных уравнений, где некоторые коэффициенты заданы буквами-параметрами. Ветвление решений в зависимости от значений параметров.

Пример: ax - 3 = 2x ⇒ (a - 2)x = 3. При a = 2 корней нет, при a ≠ 2 корень x = 3/(a - 2).
§ 5. Уравнения с модулем

Геометрический смысл модуля как расстояния на числовой оси. Раскрытие модулей методом промежутков (знакопостоянства подмодульных выражений).

Пример: |x - 1| + |x - 3| = 4. Ось разбивается точками 1 и 3 на три интервала.
§ 6. Текстовые задачи повышенной сложности

Моделирование олимпиадных задач: задачи на бассейн и трубы (совместная работа), движение навстречу с изменением скорости и задачи на разбавление концентраций.

Формула: При работе принимаем весь объём за 1, тогда общая скорость v = 1/t₁ + 1/t₂.
