Глава V. Формулы сокращенного умножения (Макарычев, База)

§ 32. Квадрат суммы и квадрат разности

Квадрат суммы двух выражений равен квадрату первого плюс удвоенное произведение первого и второго плюс квадрат второго: (a + b)2 = a2 + 2ab + b2. Для разности: (a - b)2 = a2 - 2ab + b2.

Пример: (x + 3)2 = x2 + 2*x*3 + 32 = x2 + 6x + 9.
§ 33. Разложение на множители с помощью формул квадрата суммы и разности

Трехчлен a2 + 2ab + b2 сворачивается обратно в (a + b)2, а a2 - 2ab + b2 — в (a - b)2. Это позволяет легко раскладывать многочлены на множители.

Пример: 4x2 - 12x + 9 = (2x - 3)2.
§ 34. Умножение разности двух выражений на их сумму

Произведение разности двух выражений и их суммы равно разности их квадратов: (a - b)(a + b) = a2 - b2.

Пример: (2x - 5)(2x + 5) = (2x)2 - 52 = 4x2 - 25.
§ 35. Разложение разности квадратов на множители

Разность квадратов раскладывается на произведение разности и суммы: a2 - b2 = (a - b)(a + b).

Пример: 49 - y2 = (7 - y)(7 + y).
§ 36. Разность и сумма кубов

Сумма кубов: a3 + b3 = (a + b)(a2 - ab + b2). Разность кубов: a3 - b3 = (a - b)(a2 + ab + b2). Трехчлен во второй скобке называют неполным квадратом.

Пример: x3 - 8 = (x - 2)(x2 + 2x + 4).
§ 37. Преобразование целого выражения в многочлен

Целым выражением называется выражение, не содержащее деления на переменные. Для его упрощения раскрывают скобки по формулам сокращенного умножения и приводят подобные члены.

Пример: (x - 2)2 - x(x + 3) = x2 - 4x + 4 - x2 - 3x = -7x + 4.
§ 38. Применение различных способов для разложения на множители

На практике часто комбинируют методы: 1) Вынесение общего множителя за скобки; 2) Применение формул сокращенного умножения; 3) Способ группировки.

Пример: 3x2 - 12 = 3(x2 - 4) = 3(x - 2)(x + 2).
