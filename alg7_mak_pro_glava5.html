Глава 5. Разложение многочленов на множители (Макарычев, Профиль)

§ 32. Вынесение общего множителя и группировка

Комбинированные приёмы группировки с искусственным расщеплением одного из слагаемых на сумму двух для последующего вынесения общих множителей.

Пример: x² + 5x + 6 = x² + 2x + 3x + 6 = x(x + 2) + 3(x + 2) = (x + 2)(x + 3).
§ 33. Формулы квадрата суммы, разности и разности квадратов

Применение базовых формул к сложным выражениям, содержащим степени и вложенные скобки. Разность четвертых степеней: a⁴ - b⁴ = (a² - b²)(a² + b²) = (a - b)(a + b)(a² + b²).

Пример: (x² + 2)² - 9 = (x² + 2 - 3)(x² + 2 + 3) = (x² - 1)(x² + 5) = (x - 1)(x + 1)(x² + 5).
§ 34. Куб суммы и куб разности

Формулы: (a + b)³ = a³ + 3a²b + 3ab² + b³; (a - b)³ = a³ - 3a²b + 3ab² - b³. При разложении ищут кубы крайних слагаемых и проверяют утроенные произведения.

Пример: x³ + 6x² + 12x + 8 = (x + 2)³.
§ 35. Сумма и разность кубов

Разложение: a³ ± b³ = (a ± b)(a² ∓ ab + b²). Неполный квадрат разности или суммы в действительных числах дальше на линейные множители не раскладывается.

Пример: 8x³ - 27 = (2x - 3)(4x² + 6x + 9).
§ 36. Метод выделения полного квадрата

Прибавление и одновременное вычитание одного и того же числа или выражения, чтобы получить квадрат двучлена и затем применить формулу разности квадратов.

Пример: x⁴ + 4 = (x⁴ + 4x² + 4) - 4x² = (x² + 2)² - (2x)² = (x² - 2x + 2)(x² + 2x + 2).
§ 37. Разложение многочленов с помощью корней (следствие теоремы Безу)

Если целое число c является корнем приведенного многочлена с целыми коэффициентами, то c является делителем свободного члена. Найдя корень, делят многочлен на (x - c).

Пример: Для x³ - 3x + 2 делители 2: ±1, ±2. При x = 1: 1 - 3 + 2 = 0. Значит делится на (x - 1).
§ 38. Треугольник Паскаля и бином Ньютона

Коэффициенты разложения выражения (a + b)ⁿ находятся с помощью треугольника Паскаля, где каждое число равно сумме двух стоящих над ним.

Строка для n = 4: 1, 4, 6, 4, 1 ⇒ (a + b)⁴ = a⁴ + 4a³b + 6a²b² + 4ab³ + b⁴.
§ 39. Применение разложения к решению уравнений высших степеней

Произведение равно нулю тогда и только тогда, когда хотя бы один из множителей равен нулю: A * B = 0 ⇔ A = 0 или B = 0. Это позволяет сводить кубические уравнения к линейным и квадратным.

Пример: x³ - 4x = 0 ⇒ x(x - 2)(x + 2) = 0 ⇒ x₁ = 0, x₂ = 2, x₃ = -2.
